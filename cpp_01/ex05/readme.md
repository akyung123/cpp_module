## Description
- DEBUG level : 상황 정보 포함, 문제 진단에 사용됨
- INFO level :
- WARING level :
- ERROR level :

우리는 Harl을 자동화해야합니다
Harl class는 아래와 같은 private member functions를 가지고 있어야한다
    • void debug( void );
    • void info( void );
    • void warning( void );
    • void error( void );
매개변수로 전달된 레벨에 따라서 위의 네가지 멤버 함수를 호출하는 공개 멤버 함수도 존재함
    • void complain ( std::string level );

이 연습의 목표는 멤버 함수에 대한 포인터를 사용하는 것이다
Hari는 if/else if/else 문을 사용하지 않고도 오류 발생시켜야한다.
