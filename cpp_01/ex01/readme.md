## Description

이제 좀비 떼를 만들어야 할 시간이야!
적절한 파일에 다음 함수를 구현하세요:
'
Zombie* zombieHorde( int N, std::string name );
'
단일 할당으로 N개의 Zombie 객체를 할당해야 합니다. 그런 다음, 초기화해야 합니다
zombies, 각각에 전달된 이름을 매개변수로 부여합니다. 함수는 반환값을 반환합니다
첫 번째 좀비를 가리키는 포인터입니다.
좀비가 제대로 작동하는지 확인하기 위해 직접 테스트를 구현하세요Horde() 함수는 예상대로 작동합니다. 각 좀비마다 announce()를 호출해 보세요.
모든 좀비를 해제하고 메모리를 확인하려면 delete를 사용하는 것을 잊지 마세요
누출.
