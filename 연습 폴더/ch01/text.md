01-2 함수 오버로딩(Function Overloading)

C에서는 같은 이름의 함수 오버로딩을 허용하지않지만
C++에서는 허용한다

why? : 함수 호출 시, 전달되는 인잘ㄹ 통해 호출하고자 하는 함수의 구분이 가능하기 때문
반환형이 아니라 매개변수로 결정됨

01-3 매개변수의 디폴트 값

기본적으로 설정되어있는 값을 지정할 수 있음(파이썬 동일)
디폴트 값은 함수의 선언 부분에만 표현하면 된다
 - 함수의 원형을 별도로 선언하는 경우, 매개변수의 디폴트 값은 함수의 원형 선언에만 위치시켜야한다
 - 일부만 디폴트 값을 지정할 수도 있다
    - 이때는 반드시 오른쪽 매개변수의 디폴트값부터 채우는 형태로 정의해야한다 
    - 앞에서부터가 아니라 뒤에서부터!!!
    - why? 함수에 전달되는 인자가 왼쪽에서부터 오른쪽으로 채워진다
    - ex: func(int num1, int num2)라면 func(1)하면 num1부터 채워져야한다
        그러므로 num2부터(뒤에서부터) 디폴트값을 정해야한다

01-4 인라인(inline) 함수
- 의역 : 프로그램 코드라인 안으로 들어가 버린 함수

매크로함수
- 장점 : 실행속도 up
- 단점 : 정의가 어려움

함수의 몸체 부분이 함수호출 문장을 완전히 대체했을 때, '함수가 인라인화 되었다'라고 표현한다
c++의 인라인 함수는 이러한 요구사항(매크로 장점 유지, 단점 제거)을 100% 만족한다

매크로 함수는 자료형에 의존적이지 않지만
인라인 함수는 자료형에 의존적이다
물론, 함수의 오버로딩을 통해서 해결할 수 있지만 이는 여러개의 함수를 추가하게 된다
그래서 보통 "템플렛"이라는 걸 이용한다

01-5 이름공간(namespace)에 대한 소개
- 이름공간은 말그대로 '이름을 붙여놓은 공간'이다
- 말 그대로 특정 영역에 이름을 붙여주기 위한 문법적 요소

여러 공간에 같은 이름을 사용하기 위해서
예 : 102호 철수, 205호 철수....  

*이름공간의 중첩*
이름공간은 다른 이름공간안에 삽입될 수 있다 
그럴 때는 중첩하여 접근한다
예: Parent::SubOne::num // Parent::SubTwo::num
---------------------------------------------------------------------
파일의 분할(다음 내용을 잘 알고있어야한다)
- 헤더파일의 의미와 정의 방법
- 헤더 파일에 삽입할 내용과 소스 파일에 삽입할 내용을 구분하는 방법
- 둘 이상의 헤더파일과 소스파일을 만들어서 하나의 실행방법으로 컴파일하는 방법
---------------------------------------------------------------------
using을 이용한 이름공간의 명시
- 매번 std::를 붙여하는 이유를 이제 알았다.
- using Hybrid::HybFunc; 
    : 이름공간 'Hybrid'에 정으된 HybFuc를 호출할 때는 이름공간 지정안할거임
    - 이러한 using은 선언된 지역을 벗어나면 효력을 잃는다. 
- using namespace std
    : 이름공간 std에 선언된 모든 것에 대해 이름공간 지정의 생략
---------------------------------------------------------------------
이름 공간의 별칭 지정
- namespace ABC=AAA::BBB::CCC;
    : 이름공간이 중첩될 경우, 별칭을 지정할 수도 있다

지역 변수의 이름이 전역변수와 같을 경우, 전역변수는 지역변수에 의해 가려진다
- 전역 변수 사용시에는 ::를 앞에 붙임
