# 03-1 C++에서의 구조체
구조체 : 연관 있는 데이터를 묶을 수 있는 문법적 장치

C에서는 우리는 구조체를 데이터 변수들로만 만들어보았다
그러나 이런 변수로 이루어진 구조체에 종속된 함수들이 존재한다
그럼에도 불구하고 전역함수의 꼴로 나타내어져 종속적임을 나타낼 수 없어진다
=> 다른 영역에서도 이 함수를 호출하는 실수를 범할 수 도 있다

그렇다면, 어떻게 해결하면 좋을까?

### 구조체 안에 함수 삽인하기
구조체에 종속적인 함수들을 구조체 안에 함께 묶어버리면?
확실하게 구분이 가능하다 -> C++에서는 구조체 안에 함수 삽입을 허용한다!
삽입되기 전 되기 이전의 변환
- 매개변수를 통해서 대상의 정보를 전달받지 않아도 됨
- 구조체 내에 선언된 변수에 직접 접근이 가능해짐

### 구초체 안에 enum 상수 성언
enum은 상수를 말로 정의해두는 열거형이라고 이해해두자
        enum
        {
            ID_LEN  = 20;
            MAX_SPD = 200;
        }

### 함수는 외부로 뺄 수 있다
함수가 포함되어 있는 c++ 구조체를 보는 순간, 다음의 정보들이 눈에 들어와야함
- 선언되어 있는 변수 정보
- 선언되어 있는 함수 정보

구조체에는 함수 정보면 필요하지, 함수의 자세한 구현을 알 필요가 없다
-> 파일을 따로 빼서 만든다

구조체 안에 함수가 정의되어있다면 -> 함수가 인라인으로 처리됨
밖으로 빼내면 -> 인라인으로 처리되지않음
따라서 파일 분리를 할 시, 인라인으로 처리하려면 inline 키워드를 통해 처리해야함

# 03-2 : 클래스(Class)와 객체(Object)

### 클래스와 구조체의 유일한 차이점
- 클래스는 선언된 함수가 아닌 다른 영역에서 초기화 할 수 없다
- 초기화 하려면? -> 클래스 내 함수를 통해서 혹은 자동 초기화

접근 지시자 파트라서 걍 넘어감

### 용어 정리 : 객체(Object), 멤버변수, 멤버함수
- 구조체와 클래스는 변수의 성격만 지니지않음
클래스를 구성하는 변수를 가리켜서 멤버 변수
클래스를 구성하는 함수를 가리켜서 멤버 함수라 한다

### C++에서의 파일 분할
특히 C++은 클래스 별로 헤더파일과 소스 파일을 생성해서
클래스의 선언과 정의를 분리하는 경우가 많기 때문에 많은 수의 파일이 만들어진다.

### 인라인 함수는 헤더파일에!
why? : 컴파일 과정에서 함수의 호출 문이 있는 곳에 함수의 몸체가 존재해야함

# 03-3 : 객체 지향 프로그래밍의 이해

### 객체를 이루는 것은 데이터와 기능
- 객체는 하나 이상의 상태 정보(데이터)와 하나 이상의 행동(기능)으로 구성
- 상태 정보는 변수를 통해서 표현되고
- 행동은 함수를 통해서 표현이 된다
