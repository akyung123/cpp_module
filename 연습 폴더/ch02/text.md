### 키워드 const
- const는 간단하게 말하면 고정값 선언
### 실행중인 프로그램의 메모리 공간
- 메모리 공간은 크게 데이터, 스택, 힙 영역으로 나누어진다
- 데이터 영역에는 전역/정적변수가 선언되고 시작과 동시에 할당, 종료될 때 소멸된다
- 힙 영역은 사용자에 의해 동적으로 할당되는 영역이다 (malloc, free)
- 스택 영역은 함수 호출에 따라서 발생ㄹ하는 지역변수와 매개변수, 리턴값들이 저장된다
- 함수 호출에 할당되고 호출이 종료되면 반환된다

### Call-by-value, Call-by-reference
- 함수의 호출형태는 값에 의한 호출과 참조에 의한 호출이 있다
- 간단하게 발해서 값을 넘겨주느냐, 주소를 넘겨주느냐이다.
- 값만 넘기면 원래의 함수에서의 값이 바뀌진않는다(swap함수로 이해하면 좋음)

# 02-3 참조자(Reference)의 이해

참조라자는 건 포인터와 비유가 되기 쉽다.
그러나 포인터와는 다르다. 
### 참조자(Reference)의 이해
- 변수는 할당된 메모리 공간에 붙여진 이름이고 그 이름을 통하여 해당 메모리 공간에 접근이 가능한 것이다
- 참조자는 간단하게 말하면 제 2의 이름을 부여하는 것이다
ex: int num = 2010;
    int *ptr = &num1; // num1의 주소값을 포인터 ptr에 저장한다
    int &num2 = num1; // num1에 대한 참조자 num2를 선언한다

### 참조자는 별칭이다
- 수의 제한에 없으며, 참조자를 대상으로도 참조자를 선언할 수 있다
- 미리 선언했다가 붙일 수 없고 초기화도 할 수 없다
- 배열요소도 변수의 범위에 포함된다
- 포인터 변수도 변수라서 참조자 선언이 가능한다

# 02-4 참조자(Reference)와 함수
- 참조자를 이용해서 Call-by-reference를 할 수 있다

참조자의 단점은 바로 함수의 호출문장을 보고 함수의 특성을 파악할 수 없다는 것이다
그래서 const 선언을 많이 사용한다.
참조자 ref에 const 선언을 추가한다 -> 함수 내에서 참조자 ref를 이용한 값의 변경을 하지 않겠다

## 반환형이 참조형(Reference Type)인 경우
- 참조형이면 참조형, 기본형 다 저장할 수 있고
- 반환형이 기본형이면 기본형에만 저장할 수 있다
- 지역변수를 참조형으로 반환하면 안된다(참조되는 함수가 사라짐)

상수화된 변수엥서 대한 참조자 선언
ex: const int num = 20;
    const int &ref = num;

놀라운 사실! const 참조자는 상수도 참조가 가능하다!
ex: const int &ref = 50;
- const 참조자를 이용해서 상수를 참조할 때는 '임시변수'라는 걸만들어서 그 장소에 값을 저장하고 참조자가 이를 참조하게끔 한다
why?
    int Addef(const in &num1, const int &num2)
    {
        return num1+num2;
    } 
위와 같이 정의된 함수에 인자 전달을 목적으로 변수를 선언한다는 건은 매우 복잡하다

# 02-5 malloc & free를 대신하는 new & delete


### new && delete
- 길이 정보를 인자를 받아서 길이의 문자열 저장이 가능한 배열을 생성하고 주소값 반환하는 함수

C언어에서 동적할당을 보인다면 두 가지 불편사항이 존재한다
- 할딩할 대상의 정보를 무조건 바이트 크기 단위로 전달해야한다
- 반환형이 void 포인터여서 적절한 형변환을 필요로 한다

그러나 c++에서 제공하는 키워드 new와 delete를 사용하면 이러한 불편한 점이 없어진다
### new 키워드  사용법
int *ptr1 = new int; // int형 변수의 할당
double *ptr2 = new double; // double형 변수의 할당
int *arr1 = new int[3]; // 크기가 3인 int형 배열의 할당
double *arr2 = new double[7]; // 크기가 7인 double형 배열의 할당

### delete 키워드 사용법
delete ptr1;
delete ptr2;
delete []arr1;
delete []arr2;
- 할당된 영역이 배열의 구조라면 []를 추가로 명시해줘야한다

## 객체의 생성에서는 반드시 new & delete
malloc과 free 함수의 호출이 문제가 될 수 있는 경우가 존재한다
단순하게 new와 malloc 함수의 동작 방식에는 차이가 있다 정도만 알아두자?

참조자의 선언은 상수가 아닌 변수를 대상으로만 가능하다(const가 아닌 경우)
그렇다면, new 연산자를 이용해서 할당된 메모리 공간에도 참조자 선언이 가능할까?
ex: int *ptr = new int;
    int &ref = *ptr;        // 힙 역역에 할당된 변수에 대한 참조자 선언
    ref = 20;
    cout << *ptr << endl;
